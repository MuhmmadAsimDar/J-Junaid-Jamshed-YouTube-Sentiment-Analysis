# J. Junaid Jamshed YouTube Sentiment Analysis

## Project Overview
This project analyzes publicly available YouTube comments and video engagement for J. (Junaid Jamshed), a Pakistani clothing brand.

## Objectives
- Collect public YouTube video and comment data using the YouTube Data API.
- Clean comments before analysis.
- Classify comments as positive, negative, or neutral.
- Analyze engagement and sentiment patterns.
- Provide data-driven recommendations for the brand.

## Tools and Technologies
- Python
- Google Colab
- YouTube Data API v3
- Pandas
- Matplotlib and Seaborn
- Hugging Face Transformers

## How to Run
Open the notebook in Google Colab, configure your `YOUTUBE_API_KEY` in Colab Secrets, and run the cells from top to bottom.

## Important Note
Sentiment predictions are estimates and may not accurately interpret Roman Urdu, sarcasm, or mixed-language comments.

## Security
API keys are private and must not be committed to this repository.
